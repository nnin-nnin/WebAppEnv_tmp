# Ampache 8.0.0

原生多容器 Docker Compose 环境。

## Prerequisites
- Docker Engine
- Docker Compose v2
- Network access to Docker Hub

## Quick Start
Navigate to this directory and run:
```bash
bash scripts/up.sh
```

## Access & Credentials
- URL: http://localhost:18080
- Admin Username: admin
- Admin Password: benchmark-only

## State Reset
```bash
bash scripts/reset.sh
```
